# 번들 폰트

지금은 비어 있다. 템플릿은 시스템 폰트로 폴백한다 (윈도우: 맑은 고딕/바탕, 맥: Apple SD Gothic Neo).

**폰트를 넣으면 AI 티가 가장 크게 줄어든다** — 카피 규칙보다 효과가 크다. 다만 넣기 전에 라이선스를 확인해야 한다.

| 템플릿 | 원하는 폰트 | 확인할 것 |
|---|---|---|
| newspaper | 나눔명조 | OFL. 임베딩 가능 |
| mono | Pretendard | OFL. 임베딩 가능 |
| (사진 위 타이포) | Pretendard | 〃 |
| (노트 필기체) | 손글씨 계열 | **조건이 제각각. 유료 소프트웨어 번들 가능 여부를 개별 확인** |

넣는 법: 이 폴더에 woff2를 두고 템플릿 style.css 맨 위에 `@font-face`를 추가한다.
electron-builder가 `fonts/**/*`를 이미 패키지에 포함한다.

⚠️ 판매용 배포라면 OFL이라도 재배포 조항을 다시 읽어야 한다.
